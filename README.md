# Мобильный медицинский дневник (Лабораторная работа №1)

Учебный проект по дисциплине «Разработка мобильных приложений для платформ iPhone и iPad».  
Приложение разработано для платформ Android и iOS на базе кроссплатформенного фреймворка Flutter.

## Информация о работе
- **Вариант:** 12 («Мобильный медицинский дневник со сканером бланков лабораторных анализов»).
- **Стек технологий:** Dart, Flutter (Material 3), fl_chart, intl.
- **Архитектурный шаблон:** MVVM (Model-View-ViewModel).

---

## Реализованный функционал (Лабораторная работа №1)
В рамках первой лабораторной работы спроектирован и реализован главный экран приложения, объединяющий три ключевых модуля:
1. **Интерактивный ввод симптомов:** интерактивный выбор текущих жалоб с помощью переключаемых чипов (FilterChip), регулировка степени выраженности симптомов и замера пульса через графические слайдеры.
2. **График изменения физиологических показателей:** визуализация динамики пульса за последние дни с использованием векторного линейного графика (LineChart).
3. **Хронологическая лента здоровья:** упорядоченный по времени список предыдущих записей о самочувствии с форматированием дат и цветовой индикацией тяжести состояния.

---

## Архитектура проекта
Проект строго структурирован в соответствии с шаблоном MVVM:
- `lib/models/` — структуры данных и неизменяемые сущности (Model).
- `lib/viewmodels/` — управление состоянием приложения, хранение истории и уведомление интерфейса через ChangeNotifier (ViewModel).
- `lib/views/` — декларативная верстка пользовательского интерфейса (View).
